# بناء APK عبر GitHub Actions

هذه النسخة تستخدم:
- JDK 17
- Gradle 9.3.1
- AGP 9.1.1
- Built-in Kotlin في AGP 9.x

لا يتم إنشاء Gradle Wrapper أثناء الـWorkflow. يتم تثبيت Gradle 9.3.1 مباشرة بواسطة `gradle/actions/setup-gradle`.

Workflow:
`.github/workflows/android.yml`

المهمة:
`gradle :app:assembleDebug`

الناتج:
`app/build/outputs/apk/debug/*.apk`


## التعديلات الأخيرة
- فصل شاشة قراءة العداد عن شاشة إضافة الفاتورة.
- حفظ قراءات العدادات مستقلة، مع اسم من قام بالقراءة.
- تحديث البيانات تلقائياً عند العودة للتطبيق والتنقل، دون الحاجة للخروج والدخول.
- ترتيب الفواتير والمقبوضات من الأحدث إلى الأقدم.
- إضافة وقت آخر عملية تحصيل لتحسين ترتيب المقبوضات.
- نسخة احتياطية يومية تلقائية على الهاتف، مع إمكانية ربط مجلد Google Drive ليتم رفع النسخة إليه يومياً.
- إضافة جدولة تذكير بقراءة العداد بتاريخ ووقت محددين مع إشعار.
- ترحيلات Room من الإصدار 6 حتى 10 للحفاظ على البيانات القديمة.
